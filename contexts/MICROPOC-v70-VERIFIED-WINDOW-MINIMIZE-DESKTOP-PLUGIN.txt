WHY COMPOSITION

Composition keeps that validated base byte-for-byte unchanged while making the effective darwin plugin implement the new capability. A later consolidation can fold the extension into the base only after behavior is validated.

TARGET CONTRACT
Input window is an observed descriptor from the existing window observation boundary:
- id: ephemeral observation handle
- title
- process
- pid

The id is never trusted as durable identity.

SAFE TARGETING FLOW
1. Require resolved application provider + identity.
2. Require observed id/title/process/pid.
3. Establish application context through the validated base `listWindows(application)`.
4. Read one fresh raw `agentCtrl.listWindows()` immediately before action.
5. Re-resolve target by `{title, process, pid}`.
6. No match -> WINDOW_TARGET_STALE.
7. Multiple matches -> WINDOW_TARGET_AMBIGUOUS.
8. Exactly one match -> current descriptor/action handle.
9. Record `handleRebound` when current id differs from observed id.
10. Do not select the action by the stale observed id.

NATIVE HOW
Private backend uses the v69 helper `tools/macos-window-minimized.swift`:
- `setWindowMinimized(descriptor, true)` performs native AXMinimized mutation.
- no Cmd+M.
- no AppleScript.

VERIFICATION
v69 physically proved immediate post-write AX readback can remain stale even though the mutation succeeds.
Therefore production verification must ignore immediate readback as authority and poll through:
`waitForWindowMinimized(descriptor, true)`
until AXMinimized is observed true or timeout.
