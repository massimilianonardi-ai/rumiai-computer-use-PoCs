Cause
-----

  readline "close"
  process "exit"

The shutdown operation itself is correct, but cleanup was not idempotent.

v44

  computerControlCleanupDone

First call:
  shutdownRuntime()

Subsequent calls:
  return immediately

This preserves the defensive multi-path cleanup registration while guaranteeing
one backend shutdown attempt per process.

No Computer Control operation, Provider behavior, planner behavior, or backend
selection logic is changed.
