# RumiAI Computer Use PoCs

Repository dei micro-PoC di RumiAI Computer Control.

Workflow canonico: micro-PoC minimale → static checks → ZIP → test fisico su Mac → risultato osservato → commit atomico → checkpoint → versione successiva.

Il comportamento fisicamente osservato prevale sui log; una versione è marcata VALIDATED solo dopo PASS fisico.
