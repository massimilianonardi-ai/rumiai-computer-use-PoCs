# RumiAI Computer Use documentation

Questa cartella conserva documentazione progettuale che non viene caricata dal runtime.

## Struttura

- `micro-pocs/` — contratti, diagnosi e conclusioni della sequenza incrementale v3-v82;
- `checkpoints/` — riepiloghi di milestone consolidate;
- `promotions/` — documentazione relativa alle promozioni di capability/prodotto;
- `workflows/` — procedure operative stabili per sviluppo, test e validazione.

Workflow operativo corrente per Computer Control:

```text
workflows/computer-control-development-validation-workflow.md
```

I risultati esatti e i test dei prodotti rimangono in `tests/`. I dati operativi letti dal planner rimangono in `contexts/`, mentre Provider e competenze rimangono rispettivamente in `providers/` e `skills/`.
