RumiAI Computer Control micro-PoC v69
NATIVE WINDOW MINIMIZE PRIMITIVE

STATUS
VALIDATED

PURPOSE
Validate the generic macOS Accessibility primitive required for Desktop Plugin `window.minimize` before changing production behavior.

ARCHITECTURAL CONTEXT
- agent-ctrl 0.1.4 does not expose a native `minimize-window` command.
- RumiAI Desktop Plugin contract already reserves `window.minimize`, currently DEFERRED on macOS.
- v64-v68 established that pid/index window ids are ephemeral action handles and must not be treated as durable identities.
- Therefore minimize must be implemented through a macOS-native window primitive and verified through physical state, not by extending the unsafe handle model.

APPLE AX BASIS
Apple Accessibility exposes `kAXMinimizedAttribute` for windows and `AXUIElementSetAttributeValue` for setting writable accessibility attributes. v69 validates this primitive physically before any production integration.

TEST-ONLY HELPER
`tools/macos-window-minimized.swift`

Contract:
- input: `<pid> <exact-title> <observe|minimize|restore>`
- resolve application through `AXUIElementCreateApplication(pid)`
- enumerate `kAXWindowsAttribute`
- require exactly one exact title match inside the supplied process
- read `kAXMinimizedAttribute`
- query `AXUIElementIsAttributeSettable`
- for `minimize`, set `kAXMinimizedAttribute=true`
- for `restore`, set `kAXMinimizedAttribute=false`
- read the attribute again and emit JSON
- fail closed on absent or ambiguous target

WHY TITLE IS ACCEPTABLE HERE
This helper is diagnostic only and the fixture uses a unique exact title inside one known PID. It does not define a durable public window identity. A future production operation will reuse the safe descriptor/re-resolution rules validated in v66.

VALIDATED CONCLUSIONS
1. `kAXMinimizedAttribute` is writable for the tested TextEdit window on macOS.
2. `AXUIElementSetAttributeValue(..., kAXMinimizedAttribute, true)` physically minimizes the window.
3. Setting the same attribute to false physically restores the window.
4. Immediate post-write readback is not authoritative; production verification must use state-driven re-observation.
5. The primitive requires no `Cmd+M` and no AppleScript in production.
6. Exact-title matching inside a known PID is sufficient for this diagnostic only; production targeting must follow the safe descriptor/re-resolution model validated in v66.

NON-GOALS
- No public `ComputerControl.minimizeWindow()` yet.
- No Desktop Plugin capability change yet.
- No maximize/restore contract yet.
- No Windows/Linux claim.
- No durable window identity.
