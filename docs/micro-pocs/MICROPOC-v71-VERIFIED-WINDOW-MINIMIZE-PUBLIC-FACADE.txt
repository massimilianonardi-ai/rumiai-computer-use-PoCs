RumiAI Computer Control micro-PoC v71
VERIFIED WINDOW MINIMIZE PUBLIC FACADE

STATUS
VALIDATED

PURPOSE
Expose the physically validated v70 macOS Desktop Plugin window.minimize operation through the public ComputerControl facade without leaking backend or platform-specific details.

SCOPE
- Add public ComputerControl.minimizeWindow({app, window}).
- Export minimizeWindow from app/computer-control/index.js.
- Route only through the selected Desktop Plugin minimizeWindow(application, window).
- Preserve the full observed window descriptor: id, title, process and pid.
- Propagate verified result metadata from the validated v70 plugin.
- Add a dedicated static boundary test.
- Add a dedicated physical public-facade test on macOS.

PUBLIC INPUT CONTRACT
{
  app,
  window: {
    id,
    title,
    process,
    pid
  }
}

The public facade accepts only an observed descriptor returned by the existing public listWindows boundary. It does not invent, reconstruct or weaken the descriptor.

FACADE FLOW
1. Require app.
2. Normalize the observed id/title/process/pid without discarding fields.
3. Require the observed handle.
4. Resolve the application Provider through the existing public Computer Control path.
5. Resolve the application through the selected Desktop Plugin.
6. Call desktop.minimizeWindow(resolvedApplication, fullObservedDescriptor).
7. Propagate failure closed with verified=false and v70 diagnostics.
8. Report success only when the plugin returns verified success.

SUCCESS RESULT
- ok=true
- state=MINIMIZED
- minimized=true
- verified=true
- verificationMethod=native-ax-minimized-true
- window
- observedHandle
- actionHandle
- handleRebound
- method
- actionSeconds
- observeSeconds
- totalSeconds

FAILURE RESULT
- ok=false
- plugin error/state/detail propagated
- verified=false
- observed/action handle diagnostics retained
- no facade-level fallback action

BOUNDARY REQUIREMENTS
- Public function and export exist.
- Application and observed handle are required.
- Full descriptor reaches desktop.minimizeWindow.
- Provider and Desktop Plugin application resolution are retained.
- Verified success/failure metadata is propagated.
- Success state is MINIMIZED and minimized=true.
- Effective macOS window.minimize capability remains IMPLEMENTED.
- Validated v70 Desktop Plugin minimizeWindow remains selected on darwin.

FORBIDDEN IN FACADE
- Direct agentCtrl or agent-ctrl references.
- Direct macOS minimized backend references.
- Direct Swift helper references.
- Cmd+M.
- AppleScript.
- Coordinate-based targeting.
- Title-only targeting.
- ID-only weakening of the descriptor.
- Restore/maximize/move/resize behavior.
