New public Window operation
---------------------------
getCurrentWindow({ app })

Returns current-window metadata from the backend.

The Computer Control layer does not interpret the title or infer application
semantics. The caller/Skill decides what the window metadata means.

Migration
---------
OPEN:
  old:
    legacy currentWindow()
  new:
    ComputerControl.getCurrentWindow()

OPEN still owns semantic verification:
  target became selected
  OR
  current window title reflects target

Diagnostics:
  windowObserved=true|false
  windowMethod=...
  titleMatches=true|false

Scope discipline
----------------
This version intentionally does NOT invent:
  listWindows()
  focusWindow()

Those operations belong in the Window API only after the active backend has
demonstrated concrete support or a deterministic native macOS implementation
is added.
